# 精选市场

**全中文 DSH 精选插件市场**

31 个分类大卡，每天换一批；没有中文名的插件，自动给你起一个——起过就不变。

分类大卡选方向，卡片看细节，点开就是一页说明书。

## 它解决什么问题

DSH 自带的插件页是一行一条的索引列表。插件多起来之后，只能靠搜索，
不知道自己想要什么的人无从下手。

精选市场把它重做成一个可以逛的页面：

- **分类大卡** —— 31 个分类各有一张手绘插画，按日期轮换，每天看到的不一样
- **筛选与排序** —— 按热度、星数、发布时间、安装状态过滤
- **插件详情页** —— 每个插件一页完整说明，直接在页内安装
- **已安装管理** —— 启用、停用、卸载、检查更新，支持单个更新和批量更新

## 一个别的插件市场没有的能力：中文自动取名

公共索引里有大量插件没有中文标题，直接显示英文包名，读起来很费劲。

精选市场会为每个插件生成中文名，做法分两步：

1. 先用内置规则从标题和简介里提炼，**页面立刻能显示**
2. 再让模型读完整个简介，综合判断功能定位给出更好的名字

**名字一旦确定就永久不变**，按插件包名绑定、存在本机，重装、升级、重建索引都不会改名。
只有明显坏掉的名字（比如断在词中间）才会重新生成。

**取名全程在本地完成，不向任何服务器发送数据。**

## 安装

在 DSH 的「插件」页打开「发现」，添加索引源：

```
https://chenqiuf.github.io/dsh-expert-market/index.json
```

然后搜索「精选市场」安装。安装会走与插件页相同的档案安装流程，
在弹窗里能看到完整进度。

也可以直接在终端安装：

```bash
dsh plugin add dsh-expert-market
```
